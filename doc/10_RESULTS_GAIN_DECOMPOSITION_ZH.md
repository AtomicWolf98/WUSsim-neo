# Case 1-1～1-6 结果与增益来源

## 1. 先读结论

64-seed 名义配置下，Case 1-5/1-6 确实是低功耗方案，但高收益不能归因于“独立 WUS 信号本身”。配对反事实显示：如果独立 WUS 仍保留与基线相同的 100 ms 活动尾巴，FTP3 功耗上升 36.60%，IM 功耗上升 122.97%。把尾巴从 100 ms 缩到公司提案的 8 ms 后，才获得足够大的节能并抵消频繁 WUS 监测开销；Case 1-6 再通过 EE 测量减少 MR 测量和额外睡眠转换。

因此本项目真正决定收益的前三项是：

1. `100 ms → 8 ms` 的 post-data/WUS timer 差异；
2. non-EE 与 EE 测量的功耗和它们是否唤醒 MR；
3. WUS occasion 时长与检测质量，它们决定频繁 LR 监测和错误唤醒成本。

## 3. Case 1-5 的收益从哪里来

配对 64-seed 瀑布以 Case 1-1 功耗归一：

| 业务 | 仅切换为独立 WUS，tail 仍为 100 ms | 再把 tail 100→8 ms | Case 1-5 总收益 |
|---|---:|---:|---:|
| FTP3 | -36.60 个百分点 | +84.82 个百分点 | +48.22% |
| IM | -122.97 个百分点 | +143.37 个百分点 | +20.40% |

负号表示更耗电。独立 WUS 每 5 ms 监听一次，比 FTP3/IM 的 160/320 ms C-DRX 周期频繁得多；若主接收机仍保持 100 ms tail，新增监测和唤醒成本没有被足够长的 MR 睡眠抵消。timer 缩到 8 ms 后，FTP3 的该步骤相对反事实功耗降低 62.09%，IM 降低 64.30%，成为 1-5 的主要收益。

这些中间百分点依赖所选分解顺序，可能为负或超过 100；它们相加得到端点总收益。总收益不依赖分解路径，中间归因依赖。

## 4. Case 1-6 比 1-5 多出的收益

| 业务 | 1-5→1-6 相对 1-5 降幅 | 按 1-1 归一的附加贡献 | 1-6 总收益 |
|---|---:|---:|---:|
| FTP3 | 14.39% | +7.45 个百分点 | 55.67% |
| IM | 41.79% | +33.27 个百分点 | 53.66% |

FTP3 业务较密，MR 经常因数据活动，本来就醒着；EE 测量避免的额外唤醒有限。IM 稀疏，non-EE 2 ms 测量会反复切断长睡眠并产生转换能量；EE 路径既降低测量本身功率，也避免大量 MR sleep/wake 边沿，所以附加收益更大。

8-seed raw 功耗构成支持这一解释：FTP3 1-5 相比基线的主要下降来自 MR PDCCH 活动，新增 LR 监测和更多转换会抵消一部分；IM 1-6 相比 1-5 的主要下降同时来自 non-EE 测量消失和 MR 睡眠转换减少。构成表位于 `results/gain_decomposition/energy_component_breakdown_8seed.csv`，只用于机制解释。

## 5. 哪些参数会推翻结论

以下为 8-seed 单因素切片中的 Case 1-6 收益；每个切片同时重跑基线和候选。

| 切片 | FTP3 1-6 | IM 1-6 | 解释 |
|---|---:|---:|---|
| 主配置附近、理想检测 | 59.70% | 74.17% | 错误唤醒和漏检消失。 |
| 受损检测 | 11.66%，CI 跨 0 | -68.01% | 稀疏 IM 被错误监测/唤醒成本主导。 |
| WUS MO = 4 ms | 20.73%，CI 跨 0 | -40.87% | 频繁长 MO 足以吃掉节能。 |
| LR WUS 功耗 = 45 | 51.92% | 50.19% | 短 MO 下仍为正，但收益下降。 |
| 服务率 400 kbit/ms | 45.65% | 53.13% | FTP3 的 PDSCH 活动变长。 |
| 服务率 1600 kbit/ms | 57.22% | 53.98% | FTP3 活动变短。 |
| 独立唤醒延迟 3 ms | 59.78% | 57.27% | 时延和等待活动改变。 |
| 相位偏移切片 | 约 52.96～61.32% | 约 53.37～59.47% | 日历相位会改变重叠和转换次数。 |

WUS MO 从 0.071429 ms 改为 4 ms 就能让 IM 变成负收益，说明结果对公司评估中的监测持续时间高度敏感。受损检测也能推翻结论，因此不能把名义 55.67% 外推为稳健的标准收益。

## 6. 可用于技术讨论的结论

可以使用以下表述：在单 UE、相对功耗、5 ms/2-symbol 独立 WUS、8 ms tail、1% 检测错误和公司 EE 测量模型下，Case 1-6 对 FTP3/IM 的 64-seed 配对收益分别为 55.67%/53.66%；反事实表明收益主要来自短 tail 和 EE 测量，而独立 WUS 在相同 100 ms tail 下会增加功耗。

不能把该结果写成 3GPP 同意的固定收益，也不能说 WUS PHY 本身贡献了 55.67%。
